How this method works

Filter first, then choose folders

  1. Choose one or more file-type groups.
  2. Optionally adjust individual extensions with the settings button.
  3. Expand the ranked folder tree and choose non-overlapping review scopes.

The tree uses this existing index. Changing a filter never starts another drive scan.
