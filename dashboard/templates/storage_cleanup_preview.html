What confirmation will do

Each listed regular file will be checked again and then sent to the Windows Recycle Bin. The toolkit never permanently deletes it as a fallback, never processes folders, and never requests elevation.

Windows manages Recycle Bin retention and recovery, so restoration is not guaranteed indefinitely.
